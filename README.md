# AI + SOC Cyber Home Lab

Production-grade Security Operations Center (SOC) lab with AI-powered analysis. Integrates Wazuh SIEM, NetAlertX network monitoring, Grafana visualization, a private AI triage service (local Ollama by default, free hosted LLM as a switch), and Airia AI for FIM analysis.

> **AI triage:** every Wazuh alert at level 7+ gets an AI verdict, severity, attack story, MITRE mapping and recommended actions, blended with a rule-based score. See [triage/README.md](triage/README.md).

| Component | Version | Purpose |
|-----------|---------|---------|
| Wazuh Manager | 4.14.0 | Central log collection & analysis |

| Wazuh Dashboard | 4.14.0 | Native Wazuh UI |
| NetAlertX | latest | Network discovery & monitoring |
| Grafana | 11.0.0 | Unified visualization |
| Filebeat | 8.13.0 | Log shipping to Indexer |
| Airia Forwarder | custom | FIM event → AI analysis pipeline |

## Quick Start

### Prerequisites
- Docker 24+ & Docker Compose 2+
- 8GB+ RAM, 50GB+ disk
- Airia account (for AI analysis)

### 1. Clone & Configure
```bash
git clone https://github.com/Willey2003/ai-soc-lab.git
cd ai-soc-lab
./scripts/deploy.sh generate-secrets
# Edit docker/.env with your Airia credentials
```

### 2. Deploy
```bash
# Development
./scripts/deploy.sh up

# Check status
./scripts/deploy.sh status

# Run tests
./scripts/deploy.sh test
```

### 3. Access Services
| Service | URL | Credentials |
|---------|-----|-------------|
| Grafana | http://localhost:3000 | admin / `GRAFANA_ADMIN_PASSWORD` |
| Wazuh Dashboard | https://localhost | admin / `WAZUH_ADMIN_PASSWORD` |
| NetAlertX | http://localhost:20211 | (set API token in UI) |
| Airia Forwarder | http://localhost:8010/health | API key: `HELPER_API_KEY` |
| SOC Triage queue | http://localhost:8020/?key=`TRIAGE_API_KEY` | API key: `TRIAGE_API_KEY` |

## Configuration

### Environment Variables (docker/.env)
```bash
# Wazuh
WAZUH_ADMIN_PASSWORD=          # Generated by deploy.sh
WAZUH_API_PASSWORD=            # Generated by deploy.sh

# Grafana
GRAFANA_ADMIN_PASSWORD=        # Generated by deploy.sh

# Airia (REQUIRED - get from Airia console)
AIRIA_API_URL=https://api.airia.ai/v1/agent/execute/...
AIRIA_API_KEY=your-airia-api-key

# Local forwarder API
HELPER_API_KEY=                # Generated by deploy.sh

# Network
BIND_HOST=192.168.0.50
SCAN_SUBNET=192.168.0.0/24

# NetAlertX (set after first login)
NETALERTX_API_TOKEN=

# AI triage (see triage/README.md)
LLM_PROVIDERS=ollama,heuristic # or hosted,heuristic / ollama,hosted,heuristic
OLLAMA_MODEL=llama3.2:3b
HOSTED_API_KEY=                # free Groq key for the hosted option
TRIAGE_API_KEY=                # Generated by deploy.sh
```

### Airia Agent Setup
1. Create Airia project: "Wazuh Security Analysis"
2. Create agent with: Input → AI Model → Output
3. Set system prompt from [docs/airia-playbook.md](docs/airia-playbook.md)
4. Publish agent version, copy Execution URL & API Key
5. Add to `.env` as `AIRIA_API_URL` and `AIRIA_API_KEY`

## Security Notes

- All inter-service communication uses TLS
- Read-only OpenSearch user for Grafana
- Forwarder runs as non-root with dropped capabilities
- File diffs excluded from AI analysis by default (`INCLUDE_FILE_DIFF=false`)
- UFW restricts access to management IP only
